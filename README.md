# CampusFlow · 我的大二计划

一个无需安装依赖、打开浏览器即可使用的本地学习与生活计划工具。它把学期目标、任务、循环课表、日历事件、习惯打卡、笔记、专注计时和复盘统计放在同一个工作台里。

在线体验：[bakrilivas-boop.github.io/plan](https://bakrilivas-boop.github.io/plan/)

## 快速开始

- 直接双击 `index.html`：核心功能（包括本地保存、导入/导出）可用。
- 若希望启用离线缓存和可安装 PWA，在此目录运行 `python -m http.server 8000`，然后访问 `http://localhost:8000`。

## 已包含的功能

- 总览：今日待办、习惯、课程提醒、目标进度与快捷新建。
- 未完成任务提醒：总览展示“今日未完成 / 已逾期”清单和当前行动步骤；点“完成此步”会推进到下一步，最后一步完成时自动完成整项任务。打开页面和定时检查时会提醒一次，并按“任务 ID + 截止日期 + 当前步骤”每日去重，因此推进后会继续提醒新一步。顶部铃铛可随时打开提醒中心，查看授权状态、重新开启方法并发送测试通知。
- 计划与任务：新增/编辑/完成/删除、多步骤待办（每行一步）、可展开的完整步骤清单、“现在做”高亮、优先级、截止日期、分类、逾期筛选、目标与周复盘。
- 课表：桌面七日周视图，手机端自动切换为按天纵向卡片；支持上一周/下一周、课程冲突提醒、单双周/周次范围、连续节次和 CSV 导出。
- 截图识别导入：选择课表截图后在浏览器本地使用中文 OCR，识别结果会先进入可编辑预览，确认后只追加选中课程，不覆盖原课表。首次使用需联网下载识别模型。
- 日历：月视图、考试/截止/社团/个人/调课事件、任务截止日期自动联动；任务完成或关闭联动后会自动清理对应标记。
- 日常习惯：打卡、连续天数、本周完成率、饮水/心情/睡眠/一句话记录。
- 灵感笔记：置顶、编辑、删除、周复盘自动归档。
- 学习统计：任务完成率、逾期、习惯打卡、专注时长、趋势和目标进度。
- 专注计时：25/5 风格计时、暂停/恢复、跨页面与刷新恢复、过期后自动补记完成轮次、关联任务和专注次数。
- 设置与备份：个人资料、学期设置、浅色/深色主题、提醒开关、JSON 备份恢复、CSV 导出、更新中心。手机/电脑设备通知是可选功能，只会在点击“开启设备通知”后请求系统权限；测试通知会检查网站权限、Service Worker 和浏览器通知队列，并在 Android 系统拦截时给出对应设置路径。拒绝权限不会影响站内提醒。
- 响应式与键盘：支持手机按天课表和 240px 极窄屏；侧栏遮罩、焦点管理与键盘操作已优化。页面使用 hash 路由，可分享直达链接并使用浏览器前进/后退；`N` 新建任务、`T` 回到今天、`Ctrl/Cmd + K` 搜索、`[`/`]` 切换课表周次、`Esc` 关闭弹窗。

数据保存在当前浏览器的 `localStorage`，课表图片也只在当前浏览器中识别，不会上传服务器。建议每周在“设置与备份”中导出一次 JSON。

> 提醒说明：当前版本的站内和设备通知会在网页打开期间检查；关闭浏览器后，纯静态 GitHub Pages 无法主动定时唤醒手机，重新打开会立即补查。要实现像微信一样“网页关闭后仍准时推送”，必须增加推送服务器（保存设备 PushSubscription 并按时发送 Web Push）或制作原生 Android App，这不是再申请一种前端权限就能完成。Android 和电脑浏览器可点击顶部铃铛授权；如果当前是 App 内置浏览器或厂商浏览器并显示“当前环境暂不支持”，请在提醒中心复制网址，再用 Chrome 或 Edge 打开。iPhone / iPad 需使用 iOS 16.4 或更高版本，先将网站“添加到主屏幕”，再从桌面图标打开并点击授权。浏览器曾被选择“拒绝”时，网页不能绕过系统再次弹框，请按提醒中心给出的步骤在网站权限中改为“允许”。拒绝权限不会影响站内提醒。

## 发布到 GitHub Pages

这个目录已经包含 `.github/workflows/pages.yml`，推送到 GitHub 的 `main` 分支后会自动部署。

```powershell
git init -b main
git add .
git commit -m "feat: add CampusFlow sophomore planner"
git remote add origin https://github.com/<你的用户名>/<仓库名>.git
git push -u origin main
```

仓库的 **Settings → Pages** 中将来源设为 **GitHub Actions**。部署完成后，访问 `https://<你的用户名>.github.io/<仓库名>/` 即可。
